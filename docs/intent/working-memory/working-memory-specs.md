# working-memory specs

Design: [working-memory-design.md](working-memory-design.md). Prefix `WM`. `[x]` = implemented, `[ ]` = intended but not yet implemented (gap), `[D]` = deferred. Test paths are relative to the repo root. "Context" means the `Context` class in `packages/working-memory/src/index.ts`.

## Window

- [ ] **WM-WIN-001**: When a `Context` is constructed with `max`, the system shall keep at most `max` events and, whenever a push (of a bus event or a self line) takes the count above `max`, drop the oldest event that is not among the newest `ownLines` `self` events, repeating until the count is `max`. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Bounded window -->
- [x] **WM-WIN-002**: The `Context` window shall be bounded by event count only; the system shall not evict events by age. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-WIN-003**: When `clear()` is called, the system shall remove every event from the window and reset `lastVision` to the empty string, and `last()` shall then return `undefined`. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-WIN-004**: When `last()` is called, the system shall return the most recently added event of the window, or `undefined` when it is empty. <!-- test: packages/working-memory/test/context.test.ts (empty case), packages/working-memory/test/context.test.ts (newest event) -->
- [x] **WM-WIN-005**: Where a region is configured with `brain.working_memory_events`, the salience and cortex regions shall each hold their own `Context` instance, sized to that value (default 24) through `Context.forBrain`; the two instances are fed from the same bus events and share one implementation. <!-- test: services/salience/test/salience.dispositions.test.ts, services/cortex/test/cortex.dispositions.test.ts -->
- [x] **WM-WIN-008**: When `Context.forBrain(brain)` is called, the system shall return an empty `Context` whose `max` is `brain.working_memory_events`; it shall be the only place a region reads that key. <!-- test: packages/working-memory/test/window.test.ts -->
- [x] **WM-WIN-006**: When `all()` is called, the system shall return a new array holding every context event in the window, oldest first, whose elements are the same objects the window holds (so `markSeenEvents` still matches them) and whose mutation leaves the window unchanged. <!-- test: packages/working-memory/test/context.test.ts (copy and identity), packages/working-memory/test/context.test.ts (content and order) -->
- [x] **WM-WIN-007**: When `hasSelf(id)` is called, the system shall return true if a `self` context event carrying that `id` is in the window and false otherwise. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [ ] **WM-WIN-009**: The `Context` shall protect at most `max - 1` `self` events from eviction, whatever `ownLines` it was given, so that a push always leaves room for another event.
- [ ] **WM-WIN-010**: When `Context.forBrain` is called, the system shall set the number of protected `self` events to `brain.working_memory_own_lines`.
- [ ] **WM-WIN-011**: When `Context.forBrain(brain, viewerText)` is called, the system shall apply `viewerText.max_chars`, `viewerText.max_name_chars`, `brain.input_limits.speech_max_chars` and `brain.input_limits.vision_max_chars` as the limits `push` and `transcript` use, and it shall be the only place a region reads those keys for the window; the first argument and its result are as WM-WIN-008 states.
- [ ] **WM-WIN-012**: A `Context` constructed directly, without `Context.forBrain`, shall protect 0 `self` events from eviction unless told otherwise.

## Ingest

- [ ] **WM-PUSH-001**: When `push` is given a `chat.message` bus event, the system shall append an unseen `chat` context event holding the bus event's `ts`, its `user` and `text` as bounded on intake (WM-PUSH-014, WM-PUSH-015), its `platform`, `userId` (when present) and `messageId` (when present) unchanged, `isMod`, `isSub`, and `mention` taken from `mentionsCohost`. <!-- test: packages/working-memory/test/context.test.ts (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [ ] **WM-PUSH-002**: When `push` is given a `speech.heard` bus event, the system shall append an unseen `speech` context event holding the bus event's `ts`, its `speaker` and `text` as bounded on intake (WM-PUSH-016, WM-PUSH-017). <!-- test: packages/working-memory/test/context.test.ts (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-003**: When `push` is given a bus event of any type other than `chat.message`, `vision.summary` or `speech.heard` (for example `brain.say` or `affect.state`), the system shall leave the window unchanged. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Ingesting bus events -->
- [ ] **WM-PUSH-004**: When `push` is given a `vision.summary` bus event, the system shall set `lastVision` to its text as bounded on intake (WM-PUSH-018), remove every earlier `vision` context event from the window, and append a single `vision` context event carrying the bus event's `ts`, `changed` and that bounded text, so the window holds at most one vision entry. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-005**: When a `vision.summary` with `changed: false` is pushed, the system shall mark its context event already seen (so `unseen()` does not return it) while still updating `lastVision`. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-006**: When `pushSelf(text, emotion, ts, id?)` is called, the system shall append a `self` context event stamped with `ts`, the bus `ts` of the `brain.say` event the line came from (the same publisher clock as the other kinds, so no entry carries the consumer's clock), that is already seen and carries no injection flags. <!-- test: packages/working-memory/test/context.test.ts (seen, no flags, bus ts) -->
- [x] **WM-PUSH-007**: When `pushSelf(text, emotion, ts, id)` is called with an `id`, the system shall keep that `id` on the appended `self` context event without rendering it in the transcript. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [ ] **WM-PUSH-008**: When `markFallback(id, fallbackText)` is called with no `seq`, or with `seq` 0, and a `self` context event with that `id` is in the window, the system shall record `fallbackText` on that event without moving it or changing its `seen` state and return true; when no such event is in the window it shall change nothing and return false. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [x] **WM-PUSH-009**: When `push` appends a context event it shall return that event, and when it leaves the window unchanged (WM-PUSH-003) it shall return `undefined`, so a caller that reacts to the event it just pushed holds it without reading the window. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-PUSH-011**: When `push` appends a `speech` context event for a `speech.heard` bus event that has `timing`, the system shall keep that `timing` object on the event unchanged, shall leave it off when the bus event has none, and shall not render it in the transcript. <!-- test: packages/working-memory/test/timing.test.ts -->
- [x] **WM-PUSH-013**: When `push` appends a `vision` context event for a `vision.summary` bus event that has `timing`, the system shall keep that `timing` object on the event unchanged, shall leave it off when the bus event has none, and shall not render it in the transcript. <!-- test: packages/working-memory/test/timing.test.ts -->
- [x] **WM-PUSH-012**: When `push` is given a `speech.partial` bus event, the system shall leave the window unchanged and return `undefined`, so an interim transcript never becomes a `speech` context event. <!-- test: packages/working-memory/test/timing.test.ts -->
- [x] **WM-PUSH-010**: Each `chat`, `speech` and `vision` context event shall carry `eventId`, the `id` of the bus event it was built from. <!-- test: packages/working-memory/test/context.test.ts -->
- [ ] **WM-PUSH-014**: When `push` is given a `chat.message` bus event, the system shall store the entry's `text` as `boundText(text, viewer_text.max_chars)`.
- [ ] **WM-PUSH-015**: When `push` is given a `chat.message` bus event, the system shall store the entry's `user` as `boundText(user, viewer_text.max_name_chars)`, or as `unknown` when that is empty.
- [ ] **WM-PUSH-016**: When `push` is given a `speech.heard` bus event, the system shall store the entry's `text` as `boundText(text, brain.input_limits.speech_max_chars)`.
- [ ] **WM-PUSH-017**: When `push` is given a `speech.heard` bus event, the system shall store the entry's `speaker` as `boundText(speaker, viewer_text.max_name_chars)`, or as `unknown` when that is empty.
- [ ] **WM-PUSH-018**: When `push` is given a `vision.summary` bus event, the system shall set `lastVision` and the entry's `text` to `boundText(text, brain.input_limits.vision_max_chars)`.
- [ ] **WM-PUSH-019**: When `markHeard(id, heard)` is called with a string and a `self` context event with that `id` is in the window, the system shall record `heard` on that event without moving it or changing its `seen` state and return true; when no such event is in the window it shall change nothing and return false.
- [ ] **WM-PUSH-020**: When `markHeard(id, undefined)` is called and a `self` context event with that `id` is in the window, the system shall remove the `heard` record from that event and return true.

## Forgetting a removed message (FORGET)

- [ ] **WM-FORGET-001**: When `forget` is called with a removal of `scope` `message`, the `Context` shall remove every `chat` event whose `platform` equals the removal's `platform` and whose `messageId` equals its `messageId`, and return the number removed.
- [ ] **WM-FORGET-002**: When `forget` is called with a removal of `scope` `user`, the `Context` shall remove every `chat` event whose `platform` equals the removal's `platform` and whose `userId` equals its `userId`, and shall not remove a `chat` event that has no `userId`.
- [ ] **WM-FORGET-003**: When `forget` is called with a removal of `scope` `all`, the `Context` shall remove every `chat` event whose `platform` equals the removal's `platform`.
- [ ] **WM-FORGET-004**: When `forget` is called, the `Context` shall leave every `speech`, `vision` and `self` event and every `chat` event of another platform in the window unchanged.
- [ ] **WM-FORGET-005**: When `forget` removes a `chat` event, the `Context` shall also drop it from the arrivals record of `holdArrivals`, so it is neither returned by `all()` or `unseen()` nor marked seen later.
- [ ] **WM-FORGET-006**: When `forget` is called with a removal that matches no `chat` event, the `Context` shall change nothing and return 0.

## Seen tracking

- [x] **WM-SEEN-001**: When `unseen()` is called, the system shall return exactly the context events whose `seen` flag is false, in window order. <!-- test: packages/working-memory/test/context.test.ts, packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Seen tracking -->
- [x] **WM-SEEN-002**: When `markSeenEvents(events)` is called, the system shall mark seen the context events of the window whose `eventId` equals the `eventId` of a passed event, so a copy of an event marks its original; it shall ignore passed events that were trimmed, that are `self` events or whose `eventId` matches no event of the window, and shall leave events that arrived after the list was read unseen. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-SEEN-004**: When `holdArrivals()` has been called, the system shall record each context event that `push` appends, keeping at most the window size of the newest; when `releaseArrivals()` is called it shall stop recording and mark seen every recorded event still in the window, leaving events that arrived before the hold or after the release unseen; `clear()` shall empty the record without ending the hold, and `holdArrivals()` shall start a fresh record. <!-- test: packages/working-memory/test/window.test.ts -->
- [x] **WM-SEEN-003**: When `markSeen()` is called, the system shall mark every context event in the window seen. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Seen tracking -->

## Package

- [ ] **WM-PKG-001**: The working-memory package shall declare `@cohost/bus` and `@cohost/config` only as development dependencies, because it imports them for types alone, and `@cohost/shared` as its only runtime dependency, imported only through `@cohost/shared/untrusted`. <!-- test: packages/working-memory/test/package.test.ts -->

## Transcript

- [x] **WM-TRANS-001**: When `transcript(cohostName)` is called, the system shall render the window oldest to newest as one line per event joined by a newline, and shall return the empty string for an empty window. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Transcript rendering -->
- [ ] **WM-TRANS-002**: When `transcript` renders a `chat` context event, the system shall emit `[chat] <label>: «<text>»`, inserting ` (mod)` after the label when `isMod` is true, where `<label>` is `speakerLabel(user, viewer_text.max_name_chars)` and `«<text>»` is `quoteUntrusted(text, viewer_text.max_chars)`. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Transcript rendering -->
- [ ] **WM-TRANS-003**: When `transcript` renders a `speech` context event that is not unfinished (WM-UNF-004), the system shall emit `[voice] <label>: <text>`, where `<label>` is `speakerLabel(speaker, viewer_text.max_name_chars)` and `<text>` is the stored text, not quoted. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-004**: When `transcript` renders a `vision` context event, the system shall emit `[screen] <text>`. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-005**: When `transcript(cohostName)` renders a `self` context event, the system shall emit `<cohostName>: [<emotion>] <text>`. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-006**: The working-memory segment shall own the transcript tag list: `transcript` emits `[chat]`, `[voice]` and `[screen]` for chat, speech and vision events, and the LLM layer's transcript stops (`"\n[chat]"`, `"\n[voice]"`, `"\n[screen]"`, LLM-STOP-006) are derived from that list, so a model continuing the transcript is cut at the next input line; the co-host's own line is not a stop. <!-- test: packages/working-memory/test/context.test.ts (the exported list equals the rendered tags); the stop list's side is LLM-STOP-007; the end-to-end check is a cortex-level test -->
- [x] **WM-TRANS-007**: When `transcript` renders any event, the system shall not include the event's injection flags, `isSub`, `mention` or `changed` values in the line, so an injected event renders exactly like a real one. <!-- test: packages/working-memory/test/context.test.ts (an injected event renders exactly like a real one) -->
- [ ] **WM-TRANS-008**: When `transcript` renders a `chat`, `speech` or `vision` event, the rendered event shall be exactly one line, containing no CR or LF, so that no field can forge a transcript tag or co-host line. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-TRANS-009**: The working-memory package shall export `TRANSCRIPT_TAGS`, the list `[chat]`, `[voice]`, `[screen]` that `transcript` renders for chat, speech and vision events, as the single definition of the tags that other packages derive from. <!-- test: packages/working-memory/test/context.test.ts -->
- [ ] **WM-TRANS-010**: When `transcript(cohostName)` renders a `self` context event that carries a fallback text recorded with no `seq` or `seq` 0, the system shall emit, in place of the WM-TRANS-005 line, `<cohostName>: [<emotion>] <fallback text> [your line "<text>" failed to play; this came out instead]`, replacing every `\r` and `\n` in the fallback text and the original text with a single space. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [x] **WM-TRANS-011**: When `transcript(cohostName)` renders a `self` context event with no fallback text, the system shall replace every `\r` and `\n` in the text with a single space, so the co-host's own line renders as exactly one line and its text cannot forge a transcript tag line. <!-- test: packages/working-memory/test/context.test.ts -->
- [ ] **WM-TRANS-012**: When `transcript` renders a `vision` context event, the system shall not wrap its text in `«` and `»`.
- [ ] **WM-TRANS-013**: When `transcript` renders a `self` context event, the system shall render it identically whether or not `markHeard` has recorded text on it.
- [ ] **WM-TRANS-014**: When `transcript` renders a context event of kind `chat`, `speech` or `vision`, the system shall begin the line with its tag (`[chat]`, `[voice]` or `[screen]`) and place no line break inside the rendered line, so that each such line begins with a transcript stop string (WM-TRANS-006).

## Injection flags

- [x] **WM-FLAG-001**: When `push` is given a `chat.message`, `speech.heard` or `vision.summary` bus event whose data carries `injected` and/or `remember`, the system shall keep each defined value on the resulting context event. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-002**: When `push` is given a bus event whose data carries neither `injected` nor `remember`, the system shall store a context event that has neither key, and `self` context events shall never carry them. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-003**: When `propagatedFlags(src)` is called with a source whose `injected` is truthy, the system shall return `{ injected: true }` plus `remember` when the source defines it. <!-- test: packages/working-memory/test/context.test.ts --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation (not a working-memory requirement) -->
- [x] **WM-FLAG-004**: If `propagatedFlags(src)` is called with a source that is `undefined` or whose `injected` is falsy or absent (including a real event carrying a stray `remember`), then the system shall return an empty object so real traffic never gains injection flags. <!-- test: packages/working-memory/test/context.test.ts (undefined source, stray remember) --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation -->

## Deferred: interrupted thoughts (STACK)

Design: LLD Interrupted thoughts (deferred). Prerequisite: CTX-REPLAN-001.

- [D] **WM-STACK-001**: Where speech is dynamic, the window shall keep a bounded stack of interrupted thoughts, each holding the interrupted line's `brain.say` id, its `spokenText` and its `unsaidText` from the interrupted `voice.done`, so that the cortex can resume the unsaid part later or discard it.

## Unfinished line (UNF)

Design: [working-memory-design.md § An unfinished line](working-memory-design.md#an-unfinished-line). Only an interjection writes an unfinished event (SAL-INTJ-007, CTX-INTJ-002); nothing else writes an early transcript to a window.

- [ ] **WM-UNF-001**: When `pushUnfinished(utteranceId, speaker, text, ts)` is called, the system shall append one `speech` context event flagged `unfinished` that carries `utteranceId`, `seen` true, `speaker` bounded as WM-PUSH-017 bounds it and `text` bounded as WM-PUSH-016 bounds it, and shall return that event.
- [ ] **WM-UNF-002**: When `push` is given a `speech.heard` bus event for an `utteranceId` that has an unfinished event in the window, the system shall append an ordinary unseen `speech` context event with the final's full text after it, and shall remove or change no existing event.
- [ ] **WM-UNF-003**: When `push` is given a `speech.early` or a `speech.retracted` bus event, the system shall leave the window unchanged and return `undefined` (WM-PUSH-009).
- [ ] **WM-UNF-004**: When `transcript` renders an unfinished `speech` context event, the system shall emit `[voice] <label> (unfinished): <text>` on one line, where `<label>` is `speakerLabel(speaker, viewer_text.max_name_chars)` and `<text>` is the stored text, not quoted.
- [ ] **WM-UNF-005**: While an unfinished `speech` context event's `utteranceId` has produced no `speech.heard`, the system shall keep the event until the count trimming of WM-WIN-001 removes it, and shall evict it by no age (WM-WIN-002).
- [ ] **WM-UNF-006**: When `push` is given a `speech.heard` bus event that carries an `utteranceId`, the system shall store it on the entry's `utteranceId`.

## Streamed lines

Design: LLD Streamed lines. A reply is one `self` entry that grows with its clauses.

- [ ] **WM-PUSH-021**: When `extendSelf(id, seq, text)` is called, a `self` context event with that `id` is in the window, `seq` is exactly one more than the last clause the event accepted and `text` is not empty, the system shall append `text` to the event's text, separated by one space, without moving the event or changing its `seen` state, and return true.
- [ ] **WM-PUSH-022**: When `extendSelf` is called with no such event, with a `seq` that is a duplicate or out of order, or with empty `text`, the system shall change nothing and return false.
- [ ] **WM-PUSH-023**: When `extendSelf` appends, the system shall leave the event's `fallback` and `heard` records and its `emotion` as they are.
- [ ] **WM-PUSH-024**: The system shall keep the clauses of a `self` context event in order, the first from `pushSelf` and the rest from `extendSelf`, and the event's text shall be those clauses joined by one space.
- [ ] **WM-PUSH-025**: When `markFallback(id, fallbackText, seq)` is called with a `seq` above 0 and a `self` context event with that `id` is in the window, the system shall record as the event's `fallback` text the clauses before `seq` followed by `fallbackText`, joined by one space, and return true.
- [ ] **WM-TRANS-015**: When `transcript(cohostName)` renders a `self` context event marked by `markFallback` with a `seq` above 0, the system shall emit `<cohostName>: [<emotion>] <fallback text> [the rest of your line "<clauses from seq on>" failed to play; this came out instead]`, replacing every `\r` and `\n` in the texts with a single space.
