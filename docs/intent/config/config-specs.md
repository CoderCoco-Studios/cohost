# config specs

## Config directory and seeding

- [x] **CFG-DIR-001**: When the `CONFIG_DIR` environment variable is set, `@cohost/config` `configDir()` shall return that path resolved to an absolute path, taking precedence over any workspace-root lookup. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:194 -->
- [x] **CFG-DIR-002**: When `CONFIG_DIR` is unset, `@cohost/config` `configDir()` shall return `config` under the nearest ancestor directory of the current working directory that contains `pnpm-workspace.yaml`, and `config` under the current working directory when no such ancestor exists. <!-- openspec: config § Config directory and seeding (spec says `./config`; code is a superset, see LLD Open Questions) --> <!-- test: packages/config/test/config.test.ts:182 -->
- [x] **CFG-DIR-003**: When `config.yaml`, `expressions.yaml` or `personality.md` is missing from the config directory and its matching `*.example.*` file exists, `ensureFromExample` shall copy the example to the real file, emit a `console.warn` naming both, and return the real path. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:19 -->
- [x] **CFG-DIR-004**: While the real config file already exists, `ensureFromExample` shall return its path without copying or modifying it. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:26 -->
- [x] **CFG-DIR-005**: If a config file is missing and its example is also missing, then `ensureFromExample` shall throw an error naming both paths. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:29 -->

## Environment handling

- [x] **CFG-ENV-001**: When `loadConfig` reads `config.yaml`, the system shall replace every `${VAR}` placeholder in the raw YAML text with `process.env.VAR`, and with the empty string when `VAR` is unset. <!-- openspec: config § Environment substitution --> <!-- test: packages/config/test/config.test.ts:9 -->
- [x] **CFG-ENV-002**: When a placeholder has the form `${VAR:-default}`, `substituteEnv` shall yield `default` when `VAR` is unset or empty and the value of `VAR` otherwise. <!-- openspec: config § Environment substitution --> <!-- test: packages/config/test/config.test.ts:14 -->
- [x] **CFG-ENV-003**: The system shall substitute only placeholders whose variable name matches `[A-Z0-9_]+`; placeholders with lower-case names shall be left in the text unchanged.
- [x] **CFG-ENV-004**: When `loadConfig` runs, the system shall first load `.env` from the parent directory of the config directory, setting only variables that are not already defined in `process.env`. <!-- openspec: config § Dotenv loading --> <!-- test: packages/config/test/config.test.ts:147 -->
- [x] **CFG-ENV-005**: When `loadDotEnv` parses a file, it shall accept `KEY=value`, double- or single-quoted values (quotes removed), whole-line `#` comments and blank lines, shall keep any `=` after the first in the value, shall skip lines with no `=` or an empty key, and shall do nothing when the file does not exist. <!-- openspec: config § Dotenv loading --> <!-- test: packages/config/test/config.test.ts:147 -->
- [ ] **CFG-ENV-006**: When an unquoted `.env` value is followed by whitespace and a `#` comment (the form `.env.example` uses on its API-key lines), `loadDotEnv` shall strip the comment so the variable is empty rather than set to the comment text. (Gap: `loadDotEnv` only skips whole-line comments, `packages/config/src/index.ts:70`; Compose strips inline comments, the dev loop does not.)
- [x] **CFG-ENV-007**: When `env(name)` is called and the variable is unset or empty, the system shall throw an error naming the variable and pointing at `.env`; `envOr(name, fallback)` shall return the fallback when the variable is unset or empty. <!-- openspec: config § Env helpers and URLs --> <!-- test: packages/config/test/config.test.ts:168 -->
- [x] **CFG-ENV-008**: The system shall read service-control settings (`CONTROL_ENABLED`, `CONTROL_TOKEN`, `CONTROL_BIND`, `CONTROL_RUNTIME`, `CONTROL_PROCESS_MODE`, `CONTROL_ADVANCED`) and `HEARTBEAT_INTERVAL_MS` only from `process.env` in their owning packages; `ConfigSchema` shall have no keys for them.

## Loading and validation pipeline

- [x] **CFG-LOAD-001**: When `loadConfig()` is called, the system shall seed `config.yaml` from `config.example.yaml` if missing, substitute environment placeholders, parse the YAML, validate it with `ConfigSchema` and return the typed `Config`, and while a result is cached it shall return the same object until called with `force = true`. <!-- openspec: config § Unknown key warning and caching --> <!-- test: packages/config/test/config.test.ts:111 -->
- [x] **CFG-LOAD-002**: When a YAML value is null after substitution (for example `port: ${OBS_PORT}` with the variable unset), the system shall drop that key at any nesting depth so the schema default applies instead of a validation error. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:116 -->
- [x] **CFG-LOAD-003**: If `config.yaml` fails schema validation, then `loadConfig` shall throw an error beginning `Invalid <file>:` that lists every failing key as `path: message`. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:125 -->
- [x] **CFG-LOAD-004**: If `config.yaml` fails validation and no `.env` exists in the parent of the config directory and the process is not inside a container (`/.dockerenv` absent), then the thrown error shall also tell the operator to run `cp .env.example .env`; when a `.env` is present the error shall carry no `.env` hint. <!-- test: packages/config/test/config.test.ts:130 --> <!-- test: packages/config/test/config.test.ts:135 -->
- [x] **CFG-LOAD-005**: When `config.yaml` contains keys the schema does not define, `loadConfig` shall load successfully and emit exactly one `console.warn` listing the dotted paths of the ignored keys. <!-- openspec: config § Unknown key warning and caching --> <!-- test: packages/config/test/config.test.ts:140 -->
- [ ] **CFG-LOAD-006**: When a key nested inside an array entry (for example a typo inside a `brain.salience.reflexes` item) is not defined by the schema, `loadConfig` shall include it in the unknown-keys warning. (Gap: `unknownKeys` returns nothing for arrays, `packages/config/src/index.ts:82`.)

## Schema

- [x] **CFG-SCH-001**: The `ConfigSchema` shall require the top-level sections `cohost`, `llm`, `vision`, `chat`, `brain`, `voice`, `avatar`, `ears` and `dashboard`, and non-empty `cohost.name`, `cohost.streamer`, `llm.model`, `llm.embed_model` and `vision.model`. <!-- test: packages/config/test/config.test.ts:125 -->
- [x] **CFG-SCH-002**: The `llm.provider` key shall accept `ollama`, `openai`, `anthropic`, `bedrock` or `mock`, shall treat an empty value as `ollama`, and shall default `llm.num_ctx` 8192, `llm.temperature` 0.9 (range 0 to 2), `llm.max_tokens` 120, `llm.claude.effort` `low`, `llm.claude.max_tokens` 2048 (minimum 256), `llm.claude.fallbacks` true and `llm.openai.base_url` `https://api.openai.com/v1`. <!-- openspec: config § Schema validation and defaults -->
- [x] **CFG-SCH-003**: The `ModuleSchema` (used by `brain.salience.module`, `brain.affect.module` and `brain.cortex.critic`) shall accept `kind` of `rules`, `llm` or `http`, treat an empty `kind` as `rules`, default `timeout_ms` to 1500, and reject an `llm.provider` override that has no `llm.model`, while a model without a provider and empty strings for both shall be accepted. <!-- openspec: config § Module config rules --> <!-- test: packages/config/test/config.test.ts:40 -->
- [x] **CFG-SCH-004**: Each `brain.salience.reflexes[].match` shall be a valid case-insensitive regular expression and `say` a non-empty list of non-empty strings; `on` shall default to `chat`, `speech`, `vision`, `emotion` to `surprised` and `cooldown_ms` to 30000. <!-- openspec: config § Reflex validation --> <!-- test: packages/config/test/config.test.ts:34 -->
- [x] **CFG-SCH-005**: The `brain` section shall default `working_memory_events` to 24, `salience` to `tick_ms` 1500, `cooldown_ms` 6000, `idle_chatter_ms` 90000, `reply_on_mention` true, `speak_threshold` 0.6 and `arousal_bias` 0.2, `affect` to `publish_ms` 2000, `half_life_ms` 45000 and `baseline_valence` 0.15, `memory` to `recall_k` 6 and `min_similarity` 0.35, and `cortex` to `recall_timeout_ms` 2500 and `speaking_timeout_ms` 20000. <!-- test: packages/config/test/config.test.ts:118 -->
- [x] **CFG-SCH-006**: The `voice`, `avatar`, `ears`, `vision`, `chat` and `dashboard` sections shall default `voice.voice` `af_heart`, `voice.speed` 1, `voice.sample_rate` 24000, `avatar.driver` `null` (enum `vtube-studio`, `vmc`, `null`), `avatar.fps` 30, `avatar.smoothing` 0.25, `ears.silence_ms` 700, `ears.min_speech_ms` 400, `ears.stt_model` `Systran/faster-whisper-small`, `vision.enabled` false, `vision.interval_ms` 8000, `vision.obs.port` 4455, `chat.ignore_prefixes` `["!"]` and `dashboard.port` 3000, and shall reject out-of-range values such as a negative `voice.speed`. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:125 -->
- [x] **CFG-SCH-007**: The system shall export the nine canonical emotions (`neutral`, `happy`, `laugh`, `surprised`, `smug`, `sad`, `angry`, `confused`, `think`) as the `Emotion` enum and `EMOTIONS` list, and `ExpressionMapSchema` shall accept a map of driver name to emotion-to-string entries plus an optional `gestures` string map defaulting to empty. <!-- test: packages/config/test/config.test.ts:100 -->

## Backend selection and isolation presets

- [x] **CFG-ISO-001**: When the backend-selection keys are omitted from the config, `@cohost/config` shall resolve `voice.engine` to `kokoro`, `brain.memory.store` to `postgres`, `brain.memory.embedder` to `ollama`, `chat.source` to `twitch`, `chat.fake.interval_ms` to 8000 and `ears.source` to `discord`, so the live backends are the default. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:282 -->
- [x] **CFG-ISO-002**: When a backend-selection value is an empty string after substitution (`llm.provider`, `chat.source`, `brain.memory.store`, `brain.memory.embedder`, `voice.engine`, `ears.source`), the schema shall treat it as the live default for that key.
- [x] **CFG-ISO-003**: If a backend-selection key holds a value outside its enum (for example `chat.source: irc`), then `loadConfig` shall fail validation naming that key's path. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:288 -->
- [x] **CFG-ISO-004**: `config/config.example.yaml` shall reference `LLM_PROVIDER`, `MEMORY_STORE`, `MEMORY_EMBEDDER`, `VOICE_ENGINE`, `CHAT_SOURCE`, `VISION_ENABLED` and `EARS_SOURCE` as `${VAR:-default}` placeholders, such that with none set the loaded values equal the live defaults and with one set only its key flips. <!-- openspec: config § Isolation preset variables --> <!-- test: packages/config/test/config.test.ts:256 --> <!-- test: packages/config/test/config.test.ts:268 -->
- [ ] **CFG-ISO-005**: When `AVATAR_DRIVER` is unset or empty, the loaded `avatar.driver` shall be `null` (the schema default). (Gap: `config.example.yaml:134` uses `"${AVATAR_DRIVER}"` with no default and `avatar.driver` has no blank-to-default preprocess, `packages/config/src/schema.ts:161`, so an empty value fails the enum; `avatar.vtube_studio.port` and `avatar.vmc.port` are likewise required with no default, so a config with no `.env` cannot load.)

- [x] **CFG-URL-002**: `urls.voice()` shall return `VOICE_URL` when set, otherwise `http://127.0.0.1:` followed by `VOICE_PORT` (default 8700). <!-- test: packages/config/test/config.test.ts:207 -->
- [x] **CFG-URL-003**: `urls.dashboard()` shall return `DASHBOARD_URL` when set, otherwise `http://127.0.0.1:3000`. <!-- test: packages/config/test/config.test.ts:231 -->
