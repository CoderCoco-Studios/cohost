# working-memory specs

Design: [working-memory-design.md](working-memory-design.md). Prefix `WM`. Verified against the code at git `49ba935` (audit pass 2026-11-01). Owner decisions of 2026-11-01 applied at git `1b57790`. `[x]` = implemented, `[ ]` = intended but not yet implemented (gap), `[D]` = deferred. Test paths are relative to the repo root. "Context" means the `Context` class in `packages/working-memory/src/index.ts`.

## Window

- [x] **WM-WIN-001**: When a `Context` is constructed with `max`, the system shall keep at most `max` events and, whenever a push (of a bus event or a self line) takes the count above `max`, drop the oldest events first. <!-- test: packages/working-memory/test/context.test.ts:48 --> <!-- openspec: working-memory § Bounded window -->
- [x] **WM-WIN-002**: The `Context` window shall be bounded by event count only; the system shall not evict events by age. <!-- no test --> <!-- inferred from absence of any time logic in index.ts:102-104 -->
- [ ] **WM-WIN-003**: When `clear()` is called, the system shall remove every event from the window and reset `lastVision` to the empty string, and `last()` shall then return `undefined`. Gap: `clear()` empties only the window (`packages/working-memory/src/index.ts:81-83`) and the test pins that `lastVision` survives, so after `forget_context` the cortex still puts the old screen line in the prompt and uses it as the recall query fallback. <!-- test: packages/working-memory/test/context.test.ts:60 -->
- [x] **WM-WIN-004**: When `last()` is called, the system shall return the most recently added event of the window, or `undefined` when it is empty. <!-- test: packages/working-memory/test/context.test.ts:60 (empty case; the newest-event case is used only as setup at context.test.ts:79) -->
- [x] **WM-WIN-005**: Where a region is configured with `brain.working_memory_events`, the salience and cortex regions shall each size their own `Context` to that value (default 24); the two windows are independent copies fed from the same bus events. <!-- no test (config in packages/config/src/schema.ts:102; construction at services/salience/src/salience.ts:32 and services/cortex/src/cortex.ts:35) -->
- [ ] **WM-WIN-006**: When `all()` is called, the system shall return a new array holding every context event in the window, oldest first, whose elements are the same objects the window holds (so `markSeenEvents` still matches them) and whose mutation leaves the window unchanged. Gap: `all()` returns the live internal array (`packages/working-memory/src/index.ts:84-86`). <!-- test: packages/working-memory/test/context.test.ts:14 (content and order only) -->

## Ingest

- [x] **WM-PUSH-001**: When `push` is given a `chat.message` bus event, the system shall append an unseen `chat` context event holding the bus event's `ts`, `user`, `text`, `isMod`, `isSub`, and `mention` taken from `mentionsCohost`. <!-- test: packages/working-memory/test/context.test.ts:14 (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-002**: When `push` is given a `speech.heard` bus event, the system shall append an unseen `speech` context event holding the bus event's `ts`, `speaker` and `text`. <!-- test: packages/working-memory/test/context.test.ts:14 (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-003**: When `push` is given a bus event of any type other than `chat.message`, `vision.summary` or `speech.heard` (for example `brain.say` or `affect.state`), the system shall leave the window unchanged. <!-- test: packages/working-memory/test/context.test.ts:25 --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-004**: When `push` is given a `vision.summary` bus event, the system shall set `lastVision` to its text, remove every earlier `vision` context event from the window, and append a single `vision` context event carrying the bus event's `ts`, `text` and `changed`, so the window holds at most one vision entry. <!-- test: packages/working-memory/test/context.test.ts:33 --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-005**: When a `vision.summary` with `changed: false` is pushed, the system shall mark its context event already seen (so `unseen()` does not return it) while still updating `lastVision`. <!-- test: packages/working-memory/test/context.test.ts:33 --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-006**: When `pushSelf(text, emotion)` is called, the system shall append a `self` context event stamped with the current time (`Date.now()`) that is already seen and carries no injection flags. <!-- test: packages/working-memory/test/context.test.ts:60 (seen), packages/working-memory/test/context.test.ts:107 (no flags); the timestamp is not asserted --> <!-- openspec: working-memory § Self utterances -->

## Seen tracking

- [x] **WM-SEEN-001**: When `unseen()` is called, the system shall return exactly the context events whose `seen` flag is false, in window order. <!-- test: packages/working-memory/test/context.test.ts:33, packages/working-memory/test/context.test.ts:60 --> <!-- openspec: working-memory § Seen tracking -->
- [x] **WM-SEEN-002**: When `markSeenEvents(events)` is called, the system shall mark seen only the context events that are the same objects (by identity) as the ones passed and still in the window, shall ignore passed events that were trimmed or never belonged to this `Context`, and shall leave events that arrived after the list was read unseen. <!-- test: packages/working-memory/test/context.test.ts:76 --> <!-- openspec: working-memory § Seen tracking -->
- [x] **WM-SEEN-003**: When `markSeen()` is called, the system shall mark every context event in the window seen. <!-- test: packages/working-memory/test/context.test.ts:60 --> <!-- openspec: working-memory § Seen tracking -->

## Transcript

- [x] **WM-TRANS-001**: When `transcript(cohostName)` is called, the system shall render the window oldest to newest as one line per event joined by a newline, and shall return the empty string for an empty window. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-002**: When `transcript` renders a `chat` context event, the system shall emit `[chat] <user>: <text>`, inserting ` (mod)` after the user name when `isMod` is true. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-003**: When `transcript` renders a `speech` context event, the system shall emit `[voice] <speaker>: <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-004**: When `transcript` renders a `vision` context event, the system shall emit `[screen] <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-005**: When `transcript(cohostName)` renders a `self` context event, the system shall emit `<cohostName>: [<emotion>] <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-006**: The working-memory segment shall own the transcript tag list: `transcript` emits `[chat]`, `[voice]` and `[screen]` for chat, speech and vision events, and the LLM layer's transcript stops (`TRANSCRIPT_STOPS` at `packages/llm/src/index.ts:45`: `"\n[chat]"`, `"\n[voice]"`, `"\n[screen]"`, LLM-STOP-006) mirror it, so a model continuing the transcript is cut at the next input line; the co-host's own line is not a stop. <!-- no test spans both packages: packages/working-memory/test/context.test.ts:86 pins the tags and packages/llm/test/llm.test.ts:27 pins the stop list; the cross-package check is a cortex-level test -->
- [x] **WM-TRANS-007**: When `transcript` renders any event, the system shall not include the event's injection flags, `isSub`, `mention` or `changed` values in the line, so an injected event renders exactly like a real one. <!-- test: packages/working-memory/test/context.test.ts:86 (exact-output assertion; no injected event is rendered) -->
- [ ] **WM-TRANS-008**: When `transcript` renders a `chat`, `speech` or `vision` event, the system shall replace every `\r` and `\n` in the interpolated user, speaker and text with a single space, so each event renders as exactly one line and no field can forge a transcript tag or co-host line. Gap: the fields are interpolated unescaped (`packages/working-memory/src/index.ts:93-95`), and no bus text field is constrained to one line (`packages/bus/src/events.ts:17`, `:43`, `:193`).

## Injection flags

- [x] **WM-FLAG-001**: When `push` is given a `chat.message`, `speech.heard` or `vision.summary` bus event whose data carries `injected` and/or `remember`, the system shall keep each defined value on the resulting context event. <!-- test: packages/working-memory/test/context.test.ts:107 --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-002**: When `push` is given a bus event whose data carries neither `injected` nor `remember`, the system shall store a context event that has neither key, and `self` context events shall never carry them. <!-- test: packages/working-memory/test/context.test.ts:107 --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-003**: When `propagatedFlags(src)` is called with a source whose `injected` is truthy, the system shall return `{ injected: true }` plus `remember` when the source defines it. <!-- test (indirect, other segments, no @spec): services/salience/test/salience.region.test.ts:193, :220; services/cortex/test/cortex.region.test.ts:332 --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation (not a working-memory requirement) -->
- [x] **WM-FLAG-004**: If `propagatedFlags(src)` is called with a source that is `undefined` or whose `injected` is falsy or absent (including a real event carrying a stray `remember`), then the system shall return an empty object so real traffic never gains injection flags. <!-- test (indirect, other segments, no @spec): services/salience/test/salience.region.test.ts:202, :220; services/cortex/test/cortex.region.test.ts:343; no test passes an undefined source --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation -->
