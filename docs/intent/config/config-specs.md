## Config directory and seeding

- [x] **CFG-DIR-001**: When the `CONFIG_DIR` environment variable is set, `@cohost/config` `configDir()` shall return that path resolved to an absolute path, taking precedence over any workspace-root lookup. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:198 -->
- [x] **CFG-DIR-002**: When `CONFIG_DIR` is unset, `@cohost/config` `configDir()` shall return `config` under the nearest ancestor directory of the current working directory that contains `pnpm-workspace.yaml`, and `config` under the current working directory when no such ancestor exists. <!-- openspec: config § Config directory and seeding (spec says `./config`; code is a superset, see LLD Open Questions) --> <!-- test: packages/config/test/config.test.ts:198 -->
- [x] **CFG-DIR-003**: When `config.yaml`, `expressions.yaml` or `personality.md` is missing from the config directory and its matching `*.example.*` file exists, `ensureFromExample` shall copy the example to the real file, emit a `console.warn` naming both, and return the real path. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:21 -->
- [x] **CFG-DIR-004**: While the real config file already exists, `ensureFromExample` shall return its path without copying or modifying it. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:21 -->
- [x] **CFG-DIR-005**: If a config file is missing and its example is also missing, then `ensureFromExample` shall throw an error naming both paths. <!-- openspec: config § Config directory and seeding --> <!-- test: packages/config/test/config.test.ts:21 -->

## Environment handling

- [x] **CFG-ENV-001**: When `loadConfig` reads `config.yaml`, the system shall replace every `${VAR}` placeholder in the raw YAML text with `process.env.VAR`, and with the empty string when `VAR` is unset or empty. <!-- openspec: config § Environment substitution --> <!-- test: packages/config/test/config.test.ts:10 --> <!-- test: packages/config/test/config.test.ts:119 -->
- [x] **CFG-ENV-002**: When a placeholder has the form `${VAR:-default}`, `substituteEnv` shall yield `default` when `VAR` is unset or empty and the value of `VAR` otherwise. <!-- openspec: config § Environment substitution --> <!-- test: packages/config/test/config.test.ts:10 -->
- [x] **CFG-ENV-003**: The system shall substitute only placeholders whose variable name matches `[A-Z0-9_]+`; placeholders with lower-case names shall be left in the text unchanged.
- [x] **CFG-ENV-004**: When `loadConfig` runs, the system shall first load `.env` from the parent directory of the config directory, setting only variables that are not already defined in `process.env`. <!-- openspec: config § Dotenv loading --> <!-- test: packages/config/test/config.test.ts:90 --> <!-- test: packages/config/test/config.test.ts:160 -->
- [x] **CFG-ENV-005**: When `loadDotEnv` parses a file, it shall trim each line, skip blank lines and lines that start with `#`, split each remaining line at its first `=` (any later `=` stays in the value), trim the key and the value, strip one pair of matching surrounding double or single quotes from the value, skip lines with no `=` or an empty key, and do nothing when the file does not exist. <!-- openspec: config § Dotenv loading --> <!-- test: packages/config/test/config.test.ts:160 -->
- [ ] **CFG-ENV-006**: When an unquoted `.env` value is followed by whitespace and a `#` comment (the form `.env.example` uses on its API-key lines), `loadDotEnv` shall strip that suffix, matching Compose's `env_file` parsing, so the variable is empty rather than set to the comment text; a `#` inside a quoted value is kept. Gap: `loadDotEnv` only skips whole-line comments (`packages/config/src/index.ts:74`), so in the dev loop the comment text becomes the value.
- [x] **CFG-ENV-007**: When `env(name)` is called and the variable is unset or empty, the system shall throw an error naming the variable and pointing at `.env`; `envOr(name, fallback)` shall return the fallback when the variable is unset or empty. <!-- openspec: config § Env helpers and URLs --> <!-- test: packages/config/test/config.test.ts:183 -->
- [x] **CFG-ENV-008**: The system shall read service-control settings (`CONTROL_ENABLED`, `CONTROL_TOKEN`, `CONTROL_BIND`, `CONTROL_RUNTIME`, `CONTROL_PROCESS_MODE`, `CONTROL_ADVANCED`) and `HEARTBEAT_INTERVAL_MS` only from `process.env` in their owning packages; `ConfigSchema` shall have no keys for them.

## Loading and validation pipeline

- [x] **CFG-LOAD-001**: When `loadConfig()` is called, the system shall seed `config.yaml` from `config.example.yaml` if missing, substitute environment placeholders, parse the YAML, validate it with `ConfigSchema` and return the typed `Config`, and while a result is cached it shall return the same object until called with `force = true`. <!-- openspec: config § Unknown key warning and caching --> <!-- test: packages/config/test/config.test.ts:119 -->
- [x] **CFG-LOAD-002**: When a YAML value is null after substitution (for example `port: ${OBS_PORT}` with the variable unset), the system shall drop that key at any nesting depth so the schema default applies instead of a validation error. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:119 -->
- [x] **CFG-LOAD-003**: If `config.yaml` fails schema validation, then `loadConfig` shall throw an error beginning `Invalid <file>:` that lists every failing key as `path: message`. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:134 -->
- [x] **CFG-LOAD-004**: If `config.yaml` fails validation and no `.env` exists in the parent of the config directory and the process is not inside a container (`/.dockerenv` absent), then the thrown error shall also tell the operator to run `cp .env.example .env`; when a `.env` is present the error shall carry no `.env` hint. <!-- test: packages/config/test/config.test.ts:140 --> <!-- test: packages/config/test/config.test.ts:146 -->
- [x] **CFG-LOAD-005**: When `config.yaml` contains keys the schema does not define, `loadConfig` shall load successfully and emit exactly one `console.warn` listing the dotted paths of the ignored keys. <!-- openspec: config § Unknown key warning and caching --> <!-- test: packages/config/test/config.test.ts:52 --> <!-- test: packages/config/test/config.test.ts:152 -->
- [ ] **CFG-LOAD-006**: When a key nested inside an array entry (for example a typo inside a `brain.salience.reflexes` item) is not defined by the schema, `loadConfig` shall include it in the unknown-keys warning (as `path[index].key`), and the warning text shall name the ignored keys without advice specific to any past schema migration. Gap: `unknownKeys` returns nothing for arrays (`packages/config/src/index.ts:86`), and the warning hard-codes advice about settings that "used to sit directly under brain" (`index.ts:114`).

## Schema

- [x] **CFG-SCH-001**: The `ConfigSchema` shall require the top-level sections `cohost`, `llm`, `vision`, `chat`, `brain`, `voice`, `avatar`, `ears` and `dashboard`, and non-empty `cohost.name`, `cohost.streamer`, `llm.model`, `llm.embed_model` and `vision.model`. <!-- test: packages/config/test/config.test.ts:134 -->
- [x] **CFG-SCH-002**: The `llm.provider` key shall accept `ollama`, `openai`, `anthropic`, `bedrock` or `mock`, shall treat an empty value as `ollama`, and shall default `llm.num_ctx` 8192, `llm.temperature` 0.9 (range 0 to 2), `llm.max_tokens` 120, `llm.claude.effort` `low` (one of `low`, `medium`, `high`, `xhigh`, `max`), `llm.claude.max_tokens` 2048 (minimum 256), `llm.claude.fallbacks` true and `llm.openai.base_url` `https://api.openai.com/v1`. <!-- openspec: config § Schema validation and defaults -->
- [x] **CFG-SCH-003**: The `ModuleSchema` (used by `brain.salience.module`, `brain.affect.module` and `brain.cortex.critic`) shall accept `kind` of `rules`, `llm` or `http`, treat an empty `kind` as `rules`, default `timeout_ms` to 1500, and reject an `llm.provider` override that has no `llm.model`, while a model without a provider and empty strings for both shall be accepted. <!-- openspec: config § Module config rules --> <!-- test: packages/config/test/config.test.ts:44 -->
- [x] **CFG-SCH-004**: Each `brain.salience.reflexes[].match` shall be a valid case-insensitive regular expression and `say` a non-empty list of non-empty strings; `on` shall default to `chat`, `speech`, `vision`, `emotion` to `surprised` and `cooldown_ms` to 30000. <!-- openspec: config § Reflex validation --> <!-- test: packages/config/test/config.test.ts:37 -->
- [x] **CFG-SCH-005**: The `brain` section shall default `working_memory_events` to 24, `salience` to `tick_ms` 1500, `cooldown_ms` 6000, `idle_chatter_ms` 90000, `reply_on_mention` true, `speak_threshold` 0.6 and `arousal_bias` 0.2, `affect` to `publish_ms` 2000, `half_life_ms` 45000 and `baseline_valence` 0.15, `memory` to `recall_k` 6 and `min_similarity` 0.35, and `cortex` to `recall_timeout_ms` 2500 and `speaking_timeout_ms` 20000. <!-- test: packages/config/test/config.test.ts:119 -->
- [x] **CFG-SCH-006**: The `voice`, `avatar`, `ears`, `vision`, `chat` and `dashboard` sections shall default `voice.voice` `af_heart`, `voice.speed` 1, `voice.sample_rate` 24000, `avatar.driver` `null` (enum `vtube-studio`, `vmc`, `null`), `avatar.fps` 30, `avatar.smoothing` 0.25, `ears.silence_ms` 700, `ears.min_speech_ms` 400, `ears.stt_model` `Systran/faster-whisper-small`, `vision.enabled` false, `vision.interval_ms` 8000, `vision.obs.port` 4455, `chat.ignore_prefixes` `["!"]` and `dashboard.port` 3000, and shall reject out-of-range values such as a negative `voice.speed`. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:134 -->
- [x] **CFG-SCH-007**: The system shall export the nine canonical emotions (`neutral`, `happy`, `laugh`, `surprised`, `smug`, `sad`, `angry`, `confused`, `think`) as the `Emotion` enum and `EMOTIONS` list, and `ExpressionMapSchema` shall accept a map of driver name to emotion-to-string entries plus an optional `gestures` string map defaulting to empty.
- [x] **CFG-SCH-008**: The `ConfigSchema` shall default `cohost.timezone` to `UTC`, `vision.obs.host` to `host.docker.internal`, `vision.obs.password` to the empty string, `vision.obs.source` to `Game Capture`, `vision.obs.width` to 896, `chat.twitch.channel` to the empty string, `chat.ignore_users` to an empty list, `avatar.idle_motion` to true, `avatar.vtube_studio.plugin_name` and `avatar.vtube_studio.plugin_developer` to `cohost`, `ears.discord.guild_id` and `ears.discord.voice_channel_id` to the empty string, and `llm.openai.api_key`, `llm.claude.api_key` and `llm.bedrock.region` to the empty string.
- [x] **CFG-SCH-009**: The `ModuleSchema` shall default `url` to the empty string and shall accept an `llm.provider` override only of `ollama`, `openai`, `anthropic` or `bedrock`, treating an empty override as absent and rejecting `mock` (a hook reaches the mock provider only by inheriting `llm.provider: mock`).
- [x] **CFG-SCH-010**: The `ConfigSchema` shall require the nested objects `vision.obs`, `chat.twitch`, `avatar.vtube_studio`, `avatar.vmc` and `ears.discord` (none defaults when absent), and within them a string `host` for both `avatar.vtube_studio` and `avatar.vmc`; their integer `port` fields are covered by CFG-ISO-005.
- [ ] **CFG-SCH-011**: The `brain` section shall define `brain.salience.thinking_timeout_ms` (positive integer, default 60000; how long a `thinking` cortex counts as busy, SAL-BUSY-001) and `brain.affect.baseline_arousal` (0 to 1, default 0.1; resting arousal, AFF-MOOD-006). Gap: neither key exists in `packages/config/src/schema.ts`; salience uses the literal `60_000` and affect a fixed 0.1.
- [ ] **CFG-SCH-012**: The `vision` section shall define `vision.timeout_ms` (positive integer, default 30000; describe-call timeout, EYES-DESC-006), `vision.upload_timeout_ms` (positive integer, default 10000; injected-upload fetch timeout, EYES-INJ-012) and `vision.upload_max_bytes` (positive integer, default 8388608, the dashboard's default image upload cap; EYES-INJ-013). Gap: none of the keys exists in `packages/config/src/schema.ts`.
- [ ] **CFG-SCH-013**: The `llm` section shall define `llm.timeout_ms` (positive integer, default 60000), the request timeout model-backends applies to `chat()`, `embed()` and `ping()` when the caller passes no `AbortSignal` (LLM-CHAT-008). Gap: the key does not exist in `packages/config/src/schema.ts`.

## Backend selection and isolation presets

- [x] **CFG-ISO-001**: When the backend-selection keys are omitted from the config, `@cohost/config` shall resolve `voice.engine` to `kokoro`, `brain.memory.store` to `postgres`, `brain.memory.embedder` to `ollama`, `chat.source` to `twitch`, `chat.fake.interval_ms` to 8000 and `ears.source` to `discord`, so the live backends are the default. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:241 --> <!-- test: packages/config/test/config.test.ts:304 -->
- [x] **CFG-ISO-002**: When a backend-selection value is an empty string after substitution (`llm.provider`, `chat.source`, `brain.memory.store`, `brain.memory.embedder`, `voice.engine`, `ears.source`), the schema shall treat it as the live default for that key.
- [x] **CFG-ISO-003**: If a backend-selection key holds a value outside its enum (for example `chat.source: irc`), then `loadConfig` shall fail validation naming that key's path. <!-- openspec: config § Schema validation and defaults --> <!-- test: packages/config/test/config.test.ts:241 --> <!-- test: packages/config/test/config.test.ts:304 -->
- [x] **CFG-ISO-004**: `config/config.example.yaml` shall reference `LLM_PROVIDER`, `MEMORY_STORE`, `MEMORY_EMBEDDER`, `VOICE_ENGINE`, `CHAT_SOURCE`, `VISION_ENABLED` and `EARS_SOURCE` as `${VAR:-default}` placeholders, such that with none set the loaded values equal the live defaults and with one set only its key flips. <!-- openspec: config § Isolation preset variables --> <!-- test: packages/config/test/config.test.ts:276 --> <!-- test: packages/config/test/config.test.ts:289 -->
- [ ] **CFG-ISO-005**: When `LLM_MODEL`, `EMBED_MODEL`, `VISION_MODEL`, `AVATAR_DRIVER`, `VTS_PORT` or `VMC_PORT` is unset or empty, `loadConfig` shall still load the shipped example config: `config.example.yaml` shall give the three model placeholders the `.env.example` values as `:-` defaults (`${LLM_MODEL:-qwen2.5:7b-instruct-q4_K_M}`, `${EMBED_MODEL:-nomic-embed-text}`, `${VISION_MODEL:-qwen2.5vl:3b}`) so the non-empty `llm.model`, `llm.embed_model` and `vision.model` of CFG-SCH-001 are met, `avatar.driver` shall treat an empty value as `null` (and `config.example.yaml` shall write `"${AVATAR_DRIVER:-null}"`), and `avatar.vtube_studio.port` and `avatar.vmc.port` shall default to 8001 and 39539; a non-empty `avatar.driver` outside `vtube-studio`, `vmc`, `null` shall still fail validation naming the key. Gap: `config.example.yaml:20,25,39` use `${LLM_MODEL}`, `${EMBED_MODEL}` and `${VISION_MODEL}` with no default, `config.example.yaml:134` uses `"${AVATAR_DRIVER}"` with no default, `avatar.driver` has no blank-to-default preprocess (`packages/config/src/schema.ts:167`), and both ports are required with no default (`schema.ts:173,177`), so a config with no `.env` cannot load in any service.
