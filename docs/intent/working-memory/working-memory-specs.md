# working-memory specs

Design: [working-memory-design.md](working-memory-design.md). Prefix `WM`. `[x]` = implemented, `[ ]` = intended but not yet implemented (gap), `[D]` = deferred. Test paths are relative to the repo root. "Context" means the `Context` class in `packages/working-memory/src/index.ts`.

## Window

- [x] **WM-WIN-001**: When a `Context` is constructed with `max`, the system shall keep at most `max` events and, whenever a push (of a bus event or a self line) takes the count above `max`, drop the oldest events first. <!-- test: packages/working-memory/test/context.test.ts:48 --> <!-- openspec: working-memory § Bounded window -->
- [x] **WM-WIN-002**: The `Context` window shall be bounded by event count only; the system shall not evict events by age. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-WIN-003**: When `clear()` is called, the system shall remove every event from the window and reset `lastVision` to the empty string, and `last()` shall then return `undefined`. <!-- test: packages/working-memory/test/context.test.ts:60 -->
- [x] **WM-WIN-004**: When `last()` is called, the system shall return the most recently added event of the window, or `undefined` when it is empty. <!-- test: packages/working-memory/test/context.test.ts:60 (empty case), packages/working-memory/test/context.test.ts:76 (newest event) -->
- [x] **WM-WIN-005**: Where a region is configured with `brain.working_memory_events`, the salience and cortex regions shall each size their own `Context` to that value (default 24); the two windows are independent copies fed from the same bus events. <!-- test: services/salience/test/salience.region.test.ts, services/cortex/test/cortex.region.test.ts -->
- [x] **WM-WIN-006**: When `all()` is called, the system shall return a new array holding every context event in the window, oldest first, whose elements are the same objects the window holds (so `markSeenEvents` still matches them) and whose mutation leaves the window unchanged. <!-- test: packages/working-memory/test/context.test.ts:84 (copy and identity), packages/working-memory/test/context.test.ts:14 (content and order) -->
- [x] **WM-WIN-007**: When `hasSelf(id)` is called, the system shall return true if a `self` context event carrying that `id` is in the window and false otherwise. <!-- test: packages/working-memory/test/fallback.test.ts -->

## Ingest

- [x] **WM-PUSH-001**: When `push` is given a `chat.message` bus event, the system shall append an unseen `chat` context event holding the bus event's `ts`, `user`, `text`, `isMod`, `isSub`, and `mention` taken from `mentionsCohost`. <!-- test: packages/working-memory/test/context.test.ts:14 (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-002**: When `push` is given a `speech.heard` bus event, the system shall append an unseen `speech` context event holding the bus event's `ts`, `speaker` and `text`. <!-- test: packages/working-memory/test/context.test.ts:14 (ts is masked in the assertion) --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-003**: When `push` is given a bus event of any type other than `chat.message`, `vision.summary` or `speech.heard` (for example `brain.say` or `affect.state`), the system shall leave the window unchanged. <!-- test: packages/working-memory/test/context.test.ts:25 --> <!-- openspec: working-memory § Ingesting bus events -->
- [x] **WM-PUSH-004**: When `push` is given a `vision.summary` bus event, the system shall set `lastVision` to its text, remove every earlier `vision` context event from the window, and append a single `vision` context event carrying the bus event's `ts`, `text` and `changed`, so the window holds at most one vision entry. <!-- test: packages/working-memory/test/context.test.ts:33 --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-005**: When a `vision.summary` with `changed: false` is pushed, the system shall mark its context event already seen (so `unseen()` does not return it) while still updating `lastVision`. <!-- test: packages/working-memory/test/context.test.ts:33 --> <!-- openspec: working-memory § Single vision entry -->
- [x] **WM-PUSH-006**: When `pushSelf(text, emotion, ts, id?)` is called, the system shall append a `self` context event stamped with `ts`, the bus `ts` of the `brain.say` event the line came from (the same publisher clock as the other kinds, so no entry carries the consumer's clock), that is already seen and carries no injection flags. <!-- test: packages/working-memory/test/context.test.ts (seen, no flags, bus ts) -->
- [x] **WM-PUSH-007**: When `pushSelf(text, emotion, ts, id)` is called with an `id`, the system shall keep that `id` on the appended `self` context event without rendering it in the transcript. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [x] **WM-PUSH-008**: When `markFallback(id, fallbackText)` is called and a `self` context event with that `id` is in the window, the system shall record `fallbackText` on that event without moving it or changing its `seen` state and return true; when no such event is in the window it shall change nothing and return false. <!-- test: packages/working-memory/test/fallback.test.ts -->
- [x] **WM-PUSH-009**: When `push` appends a context event it shall return that event, and when it leaves the window unchanged (WM-PUSH-003) it shall return `undefined`, so a caller that reacts to the event it just pushed holds it without reading the window. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-PUSH-010**: Each `chat`, `speech` and `vision` context event shall carry `eventId`, the `id` of the bus event it was built from. <!-- test: packages/working-memory/test/context.test.ts -->

## Seen tracking

- [x] **WM-SEEN-001**: When `unseen()` is called, the system shall return exactly the context events whose `seen` flag is false, in window order. <!-- test: packages/working-memory/test/context.test.ts:33, packages/working-memory/test/context.test.ts:60 --> <!-- openspec: working-memory § Seen tracking -->
- [x] **WM-SEEN-002**: When `markSeenEvents(events)` is called, the system shall mark seen the context events of the window whose `eventId` equals the `eventId` of a passed event, so a copy of an event marks its original; it shall ignore passed events that were trimmed, that are `self` events or whose `eventId` matches no event of the window, and shall leave events that arrived after the list was read unseen. <!-- test: packages/working-memory/test/context.test.ts -->
- [x] **WM-SEEN-003**: When `markSeen()` is called, the system shall mark every context event in the window seen. <!-- test: packages/working-memory/test/context.test.ts:60 --> <!-- openspec: working-memory § Seen tracking -->

## Package

- [x] **WM-PKG-001**: The working-memory package shall declare `@cohost/bus` and `@cohost/config` only as development dependencies, because it imports them for types alone, so installing it pulls in no runtime dependency. <!-- test: packages/working-memory/test/package.test.ts -->

## Transcript

- [x] **WM-TRANS-001**: When `transcript(cohostName)` is called, the system shall render the window oldest to newest as one line per event joined by a newline, and shall return the empty string for an empty window. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-002**: When `transcript` renders a `chat` context event, the system shall emit `[chat] <user>: <text>`, inserting ` (mod)` after the user name when `isMod` is true. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-003**: When `transcript` renders a `speech` context event, the system shall emit `[voice] <speaker>: <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-004**: When `transcript` renders a `vision` context event, the system shall emit `[screen] <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-005**: When `transcript(cohostName)` renders a `self` context event, the system shall emit `<cohostName>: [<emotion>] <text>`. <!-- test: packages/working-memory/test/context.test.ts:86 --> <!-- openspec: working-memory § Transcript rendering -->
- [x] **WM-TRANS-006**: The working-memory segment shall own the transcript tag list: `transcript` emits `[chat]`, `[voice]` and `[screen]` for chat, speech and vision events, and the LLM layer's transcript stops (`"\n[chat]"`, `"\n[voice]"`, `"\n[screen]"`, LLM-STOP-006) are derived from that list, so a model continuing the transcript is cut at the next input line; the co-host's own line is not a stop. <!-- test: packages/working-memory/test/context.test.ts:161 (the exported list equals the rendered tags); the stop list's side is LLM-STOP-007; the end-to-end check is a cortex-level test -->
- [x] **WM-TRANS-007**: When `transcript` renders any event, the system shall not include the event's injection flags, `isSub`, `mention` or `changed` values in the line, so an injected event renders exactly like a real one. <!-- test: packages/working-memory/test/context.test.ts (an injected event renders exactly like a real one) -->
- [x] **WM-TRANS-008**: When `transcript` renders a `chat`, `speech` or `vision` event, the system shall replace every `\r` and `\n` in the interpolated user, speaker and text with a single space, so each event renders as exactly one line and no field can forge a transcript tag or co-host line. <!-- test: packages/working-memory/test/context.test.ts:147 -->
- [x] **WM-TRANS-009**: The working-memory package shall export `TRANSCRIPT_TAGS`, the list `[chat]`, `[voice]`, `[screen]` that `transcript` renders for chat, speech and vision events, as the single definition of the tags that other packages derive from. <!-- test: packages/working-memory/test/context.test.ts:161 -->
- [x] **WM-TRANS-010**: When `transcript(cohostName)` renders a `self` context event that carries a fallback text, the system shall emit, in place of the WM-TRANS-005 line, `<cohostName>: [<emotion>] <fallback text> [your line "<text>" failed to play; this came out instead]`, replacing every `\r` and `\n` in the fallback text and the original text with a single space. <!-- test: packages/working-memory/test/fallback.test.ts -->

## Injection flags

- [x] **WM-FLAG-001**: When `push` is given a `chat.message`, `speech.heard` or `vision.summary` bus event whose data carries `injected` and/or `remember`, the system shall keep each defined value on the resulting context event. <!-- test: packages/working-memory/test/context.test.ts:107 --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-002**: When `push` is given a bus event whose data carries neither `injected` nor `remember`, the system shall store a context event that has neither key, and `self` context events shall never carry them. <!-- test: packages/working-memory/test/context.test.ts:107 --> <!-- openspec: working-memory § Injection flags retained -->
- [x] **WM-FLAG-003**: When `propagatedFlags(src)` is called with a source whose `injected` is truthy, the system shall return `{ injected: true }` plus `remember` when the source defines it. <!-- test: packages/working-memory/test/context.test.ts:172; indirect (other segments): services/salience/test/salience.region.test.ts:193, :220, services/cortex/test/cortex.region.test.ts:332 --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation (not a working-memory requirement) -->
- [x] **WM-FLAG-004**: If `propagatedFlags(src)` is called with a source that is `undefined` or whose `injected` is falsy or absent (including a real event carrying a stray `remember`), then the system shall return an empty object so real traffic never gains injection flags. <!-- test: packages/working-memory/test/context.test.ts:179 (undefined source, stray remember); indirect (other segments): services/salience/test/salience.region.test.ts:202, :220, services/cortex/test/cortex.region.test.ts:343 --> <!-- openspec: add-test-injection salience/cortex § Injection flag propagation -->
